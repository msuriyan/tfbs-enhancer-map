Page setup & export
The preview shows exactly what gets exported. With a page size set, the figure is scaled to fit the page. For many CREs, use CRE columns or CREs per page to keep text readable.

Each CRE as a separate file

One file per shown CRE, named after its label, with its own legend. All files arrive in a single ZIP.

Both include only the TFs in the current figure's legend, so hidden TFs and the shared-TF filter are respected. The table lists each TF's color, label, original motif name, sites on + and − strands, how many CREs contain it, and (optionally) counts per CRE.
